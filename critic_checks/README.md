# Скрипты агента-критика (AGENT 09), раунд 1

Скрипты независимой критики (`reports/CRITIC_round1.md`), перенесённые из временной папки агента.
Главные:
- `t2_throat_counterexample.py` — контрпример к Теореме 2 при немонотонном площадном радиусе («мешок с золотом» за горловиной, ρ ≥ 0, p_r ≤ ρ, NEC нарушено). Наш повторный запуск: α_cav = 0.0100 при оценке 0.7815.
- `t3_sharpness.py` — семейство, насыщающее Теорему 2 (нарушает NEC по касательному давлению).
- `t8b.py`, `t8c.py` — доводка DEC-оптимума до M/r_in = 0.66824 (Z = 10).
- `t18_radnec_controls.py`, `t19_nec_family.py`, `t20_nec_random.py` — поиски при NEC; сходятся к тонкой оболочке (0.495).
- `t4_stability.py`, `t21_blp.py` — независимый вывод β²_min и обобщение на массу внутри.

Запуск: `python critic_checks/<script>.py` из корня репозитория.
